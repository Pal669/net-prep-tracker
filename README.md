# NET Prep Tracker

Live tracker for UGC NET Economics preparation (Paper II, code 01, and Paper I, code 00): syllabus coverage, accuracy by unit / topic / question format, strengths and weaknesses, revision due, pace to the exam, and rule-based nudges.

- `data/tracker.json` is generated by `Economics/tracker/build_tracker.py` in the private EA Demo workspace (never edit it by hand).
- Presentation only here: `index.html`, `style.css`, `app.js`. No libraries; charts are plain SVG/HTML.
- Pushing to `main` deploys via GitHub Pages.
